Design system automation

Change it once in Figma. It ships everywhere.

Echo UI turns every Figma update into code, Storybook and AI-ready docs. AI writes the components, a person approves them, and AI checks that everything stays aligned.

How it works

One source of truth. Four jobs done for you.

Figma stays the source of truth. Everything after it is automated, with one person approving new components.

01 · Sync

Tokens flow on their own

Change a colour, spacing or radius in Figma and push. The code, docs and Storybook update in about a minute.

tokens.css
--color-primary: #e60053;
--radius-md: 8px;
--spacing-md: 16px;
02 · Build

AI writes the component

Publish a component in Figma. AI writes the code, styles and stories using tokens only, then opens a pull request for a person to approve.

Input.jsx · Input.css · Input.stories.jsx
Every colour is a token
Waiting for review
03 · Document

Docs that write themselves

Storybook shows every component in Light and Dark. One Markdown file describes the whole system for people and AI tools.

LightButton
DarkButton
04 · Audit

AI checks it all lines up

After every release, AI compares Figma, the code, Storybook and the Markdown file, and reports anything that drifted.

    Built for AI tools

    One file. Any AI tool builds on-brand UI.

    design-system.md is rebuilt on every push. Give it to Claude, Cursor or any assistant, and it uses your real components and tokens instead of guessing.

    • Rules first: use components, style with tokens only
    • Every token with Light and Dark values
    • Every component: props, allowed values, Figma mapping, example
    • Always matches the shipped code, because it is built from it
    design-system.md
    #### Input
Matches the "Input" component set in Figma.

- Import: import { Input } from "ds-poc";
- Tokens used: --color-border --radius-md …

| Prop     | Default  | Options                 |
| size     | "small"  | small · medium · large  |
| error    | false    | true · false            |
| disabled | false    | true · false            |

```jsx
<Input size="small" />
```
